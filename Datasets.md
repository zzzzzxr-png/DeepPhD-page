## Data availability

<!-- VERBATIM: v13 Data availability. -->
We have no restriction on data availability. All microscopy recordings used in this study have been archived and made publicly available at [https://zenodo.org/records/14580256](https://zenodo.org/records/14580256). The source data for neuroethological research of freely behaving mice, including calcium imaging data and synchronized behavioral recordings, are publicly available at [https://zenodo.org/records/14586426](https://zenodo.org/records/14586426).

## Code availability

<!-- VERBATIM: v13 Code availability. -->
All relevant resources are readily accessible on our GitHub page [https://cabooster.github.io/DeepPhD/](https://cabooster.github.io/DeepPhD/). The source Python code of DeepPhD can be found at [https://github.com/cabooster/DeepPhD](https://github.com/cabooster/DeepPhD) with a non-commercial research license. Our specially designed user-friendly GUI and accompanying tutorial can be found at [https://cabooster.github.io/DeepPhD/Tutorial/](https://cabooster.github.io/DeepPhD/Tutorial/).
